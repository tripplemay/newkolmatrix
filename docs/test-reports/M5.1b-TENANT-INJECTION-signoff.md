- **`find … -exec cat {} + | shasum` 不能用作内容对账判据** —— 对未改动内容三次给出三个不同哈希
  （`-exec … {} +` 批处理/遍历顺序不稳定），会给出**假的「还原失败」信号**。
  稳定形式：`find … -type f | sort | xargs cat | shasum -a 256`。
  - 来源：M5.1b rv4
  - 建议写入：`framework/patterns/testing-env-patterns.md`
- **黑名单式否定断言（「不含 X」）永远漏掉没想到的第 N 种写法。** 本批 F003 acceptance ⑤ 的旧守卫
  （「BOOTSTRAP_WHITELIST 后 200 字内没有 process.env」）被 `[...deriveFromScan()]` 一击穿透。
  修法是改成**正向白名单**（骨架里允许出现的标识符只有这 6 个），我已实测其鉴别力（§6.7）。
